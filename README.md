1. Download the .m3u and XML Guide to a permanent folder, for example: C:\User\

2. In Jellyfin, open Dashboard > Live TV > Tuner Devices > Add. Select "M3U Tuner" and enter the full local file path: C:\User\JellyfinIPTV.m3u. Leave the user agent empty. Save.

3. Under Dashboard > Live TV > TV Guide Data Providers > Add, choose "XMLTV" and enter: C:\User\JellyfinGuide.xml. If prompted for a country, choose United States. Save.

4. Run Dashboard > Scheduled Tasks > Refresh Guide, or use the Live TV "Refresh Guide" button. Channel numbers start at 1.
